# Personal Portfolio Website — Assignment 2

## Project Description

This is my personal portfolio website created for INFR 3120 Assignment 2. It introduces me, my education, interests, and coursework.

The website was developed using Node.js, Express.js, and EJS. Bootstrap and Font Awesome were used for the layout, styling, and icons.

## Website Pages

The website contains four pages:

- **Home:** A short introduction about me.
- **About Me:** Information about my education and interests in cybersecurity.
- **Projects:** Information about my portfolio website project.
- **Contact Me:** Links to my GitHub and LinkedIn profiles.

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Install the required dependencies using `npm install`.
5. Start the application using `npm start`.
6. Open `http://localhost:3000` in your browser.

## Project Structure

- `app.js` — Configures the Express application.
- `server.js` — Starts the web server.
- `routes/` — Contains the Express routes.
- `views/` — Contains the EJS pages.
- `views/partials/` — Contains the shared header, navigation, and footer.
- `public/stylesheets/` — Contains the CSS styling.
- `package.json` — Contains project dependencies and startup commands.
